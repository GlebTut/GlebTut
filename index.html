Project 01 · 2026 – Present

C2obra – Branch Coverage Tool for C Programs

Built an automated branch coverage instrumentation tool for C programs as a research-focused final-year project. Implemented AST-based source parsing with tree-sitter to detect and instrument if/else, while, for, and switch branches. Created a Python pipeline that injects a C runtime library, records branch hit counters, and generates HTML coverage reports. Evaluated the tool against TestCoCa, TestCov, and Sikraken using standardized benchmark programs.
