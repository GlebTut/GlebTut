Final-year project · 2026 – Present

C2obra – Branch Coverage Instrumentation Tool for C

  • Uses tree-sitter AST parsing to detect and instrument if, while, for, do-while, switch, and ternary branches in C source code.
  • Injects a custom C runtime library that records branch hit counters during execution.
  • A Python pipeline runs Sikraken-generated test inputs in parallel and produces HTML and CSV coverage reports.
  • GitHub Actions CI/CD runs the tool across benchmarks in parallel and publishes the reports to GitHub Pages.
  • Tested on Test-Comp benchmark programs and evaluated against TestCoCa, TestCov, and Sikraken. I also designed the architecture, drew the UML diagrams, and wrote the technical documentation.
