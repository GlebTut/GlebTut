Дипломный проект · 2026 – н. в.

C2obra — инструмент измерения покрытия ветвей для C

  • С помощью AST-парсинга на tree-sitter находит и инструментирует ветви if, while, for, do-while, switch и тернарные операторы в исходном коде на C.
  • Внедряет собственную runtime-библиотеку на C, которая считает срабатывания каждой ветви во время выполнения.
  • Конвейер на Python параллельно запускает тестовые входные данные, сгенерированные Sikraken, и формирует отчёты о покрытии в HTML и CSV.
  • CI/CD в GitHub Actions параллельно прогоняет инструмент на бенчмарках и публикует отчёты на GitHub Pages.
  • Протестирован на бенчмарк-программах Test-Comp и сравнён с TestCoCa, TestCov и Sikraken. Также спроектировал архитектуру, подготовил UML-диаграммы и техническую документацию.
