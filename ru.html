Проект 01 · 2026 – настоящее время

C2obra – инструмент покрытия ветвей для C-программ

Разработал автоматизированный инструмент инструментирования branch coverage для C-программ в рамках исследовательского дипломного проекта. Реализовал AST-парсинг через tree-sitter для поиска и инструментирования ветвей if/else, while, for и switch. Создал Python-конвейер, который внедряет C runtime-библиотеку, ведёт счётчики срабатываний и генерирует HTML-отчёты покрытия. Сравнил решение с TestCoCa, TestCov и Sikraken на стандартизированных benchmark-программах.

C Python Bash Make Linux tree-sitter Gcov/LCOV
